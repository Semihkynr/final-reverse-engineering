📌 Proje Hakkında — Ne İstendi?

BGT210 — Reverse Engineering dersi kapsamında öğrencilerden, gerçek dünya senaryolarında kullanılabilecek bir tersine mühendislik metodolojisi ve bunu destekleyen çalışan bir araç seti geliştirmeleri istenmiştir.

Dersin Beklentileri

  • ✓ Binary dosyaları analiz eden çalışan bir implementasyon
  • ✓ Static analysis, dynamic analysis, network monitoring fazlarının belgelenmesi
  • ✓ Araç karşılaştırması ve seçim kriterleri
  • ✓ MITRE ATT&CK ile eşleştirme yapabilme
  • ✓ Profesyonel raporlama şablonu
  • ✓ Docker ile çalışan ortam
  • ✓ Araştırma süreci ve öğrenme yolculuğu (ROADMAP)

Neden Bu Proje Önemli?

Zararlı yazılımların analizi, siber güvenliğin en kritik alanlarından biridir. Bir binary'yi çalıştırmadan önce statik olarak incelemek (static analysis), ardından sandbox ortamında gözlemlemek (dynamic analysis), ve ürettiği ağ trafiğini yakalamak (network monitoring) — bu üç fazın sistematik ve tekrarlanabilir biçimde uygulanması, bir malware analistinin temel yetkinliğini oluşturur.

Python Araç Seti

  • ✓ analyzer.py — PE hash, entropy, import analizi, risk skoru
  • ✓ pe_parser.py — external kütüphane olmadan manuel PE header ayrıştırması
  • ✓ string_extractor.py — ASCII + wide string, base64 decode, pattern matching
  • ✓ report_generator.py — JSON → Markdown rapor + MITRE ATT&CK mapping
  • ✓ run.sh — tek komutla demo çalıştırma scripti

Modül Dokümantasyonları

Static Analysis
Dosya triage · Magic byte tespiti · PE header analizi · Section entropy · Import table · String extraction · Disassembly (Ghidra) · YARA rule matching
Dynamic Analysis
Sandbox ortamı kurulumu · ProcMon ile izleme · x64dbg debugger stratejisi · Anti-debug bypass · Memory dump · API call logging · Behavior timeline
Network Monitoring
Wireshark packet capture · DNS/HTTP analizi · TLS intercept · C2 beaconing tespiti · DNS tunneling · IOC extraction · MITRE mapping
